# Screenshots to capture

`README.md` references `docs/images/dashboard.png`, which does not exist yet.

## What to capture

**One screenshot, `dashboard.png`.** Run the quick start, create two or three
pages and a post so the dashboard has real numbers in its tiles rather than
zeros, then capture the dashboard at a desktop window width (~1440px).

The tiles and the "Recently updated" table together show it is a working CMS
rather than a settings form. A dashboard full of zeros sells nothing.

## Phone-friendly capture

- A direct screenshot (`⇧⌘4`, space, click the window) is always sharper than
  photographing the screen. Use that if you can.
- If recording on your phone: full-screen the browser first (`⌃⌘F`), landscape,
  braced against something solid, angled slightly away from any light source.

## Before you commit it

Nothing here is client data — it is your own local test content — but check the
frame for your browser bookmarks bar and any other open tabs.

Save as `docs/images/dashboard.png`, under 500 KB. Then delete this file.
